# Chrome 股票桌面設計規格

狀態：使用者已回覆「OK」核准，進入實作。市場範圍為台股＋美股。

## 使用形式與方案

採 Chrome Manifest V3 新分頁擴充功能。開啟新分頁即可看股票，關閉新分頁後仍由背景工作程序檢查到價條件。資料保存在本機，第一版無須建立本產品帳號或架設伺服器。

評估的替代方案：一般網頁容易開啟，但頁面關閉後無法持續監控；獨立桌面程式可獨立於 Chrome 運行，但增加安裝與維護成本。新分頁擴充功能最符合這次需求。

## 股票與持股

- 支援台股上市、上櫃個股與 ETF，以及美股個股與 ETF；新增時選擇市場並輸入股票代號。
- 每張卡片呈現名稱、代號、市場、幣別、目前報價、當日漲跌、資料時間與連線狀態。
- 可以只追蹤，也可以填入正數的每股買入均價及持股數量。台股數量以「股」輸入，美股可輸入小數股。
- 點選個別卡片的損益數字切換百分比／金額，並保存選擇。損益百分比＝（目前價－均價）÷均價×100%；金額＝（目前價－均價）×股數。
- 未填股數時只顯示每股價差，明確標示「每股」。損益不含手續費、交易稅與股息；不同幣別不直接相加。
- 第一版不包含交易下單、券商庫存同步或匯率換算。

## 分區與排列

預設提供「台股」、「美股」兩個空白分區，可新增、重新命名、排序及刪除分區。刪除非空分區時必須選擇將卡片移到其他分區或一併移除，並明確確認影響。卡片可拖曳排列及跨分區移動，也提供選單操作作為鍵盤替代。每張卡片可編輯、移動及移除。

## 行情來源與更新

建議台股使用 Fugle、美股使用 Finnhub 的個人行情 API。使用者在設定頁填入自己的 Key；金鑰僅保存在擴充功能本機儲存區，欄位遮蔽顯示，不進入日誌或原始碼。未設定時顯示「尚未連接行情」，不填入模擬價格。

台股 Fugle 基本方案目前提供每分鐘 60 次日內 REST API 請求；美股採 Finnhub Quote。實作前依兩者官方文件確認各自限額。第一版採即時行情快照輪詢，預設目標每 30 秒檢查一次，不宣稱逐筆推播或毫秒級提醒。依每個來源的額度、追蹤數量及錯誤退避調整實際頻率，並在介面顯示實際更新狀態。

單一背景工作程序統一排程；同一股票即使出現在多個分區也共用報價請求，多個新分頁不增加重複輪詢。網路失敗、無效代號、金鑰錯誤與限流須分別顯示，保留最後成功價格與時間並標示過期。休市不顯示為正在交易，舊報價不標成剛更新。交易時間依市場時區處理，並以供應商回傳狀態及時間為準。

## 價格提醒

- 每張卡片可分別設定「高於」及「低於」價格，使用嚴格大於／小於；價格相等不觸發。若上下界同時設定，下界須小於上界。
- 每條規則第一次取得有效且新鮮的報價時，若符合條件即通知一次。後續需先回到不符合條件的區間，再次跨越才重複提醒；修改規則會重新啟用。
- 保存觸發狀態，跨分頁、重新載入及背景程序重啟不重複通知。先保存狀態再送通知，避免競態；通知失敗需留下可見狀態及重試入口。
- 通知顯示股票、當前價、觸發條件、幣別與報價時間。首次啟用時請求通知權限，提供測試通知按鈕。
- 不使用快取重播、失敗回應、無效價格或超過 120 秒的成交資料觸發提醒；低成交量標的因此可能延後到下一筆有效成交才判斷。
- Chrome 完全結束、電腦休眠或離線期間無法保證監控；恢復後取得新報價才判斷，不宣稱補發期間內所有跨價事件。

## 視覺與背景

介面使用台灣繁體中文。滿版風景背景搭配深色、高對比的卡片；頂部放日期、行情連線狀態、新增股票與設定入口，中段依分區排列卡片，角落顯示可點擊的照片作者與出處。漲跌與持股損益以正負號和文字表達，配合台灣慣用紅漲綠跌，不能只靠顏色辨識。

視窗較窄時卡片自動換行。表單具可見標籤、就地錯誤、鍵盤焦點與 Escape 關閉；尊重減少動態效果設定。設定採側邊抽屜，將持股、提醒與背景選項分組，避免主畫面擁擠。

預設十張照片已確認為 CC0，原圖最短寬度為 3,264 像素，清單見 [照片來源](../../research/backgrounds.md)。實作時打包最佳化圖片及縮圖，保留作者、來源頁、授權連結。使用者可以切換照片，或上傳 JPEG／PNG／WebP 自訂背景；上傳以 15 MB 為限，檢查實際能否解碼，保存在本機。提供背景亮度調整與還原預設。自訂圖片不會上傳到第三方。

## 技術邊界

使用 TypeScript、React 與 Vite 建置前景介面，純 TypeScript 模組處理行情轉換、損益計算及提醒規則，Manifest V3 service worker 處理排程、行情請求與通知。使用 chrome.storage.local 保存設定、持股與提醒狀態，IndexedDB 保存自訂圖片。權限限於儲存、排程、必要的通知與兩個行情網域。

模組分為 UI、資料儲存、行情供應商、更新排程、提醒引擎與照片目錄，透過明確型別交換資料。所有執行程式碼都隨擴充功能打包。

## 驗收

1. 可以新增、編輯、移除台股與美股標的，分區與排序重啟後保留。
2. 損益在漲、跌、零變化、小數股、未填股數等情境計算正確，點擊切換可保存。
3. 高低價相等不觸發、跨越觸發、持續符合不重複；重啟、多分頁及過期資料行為有自動化測試。
4. 金鑰未設定／無效、HTTP 429、離線、無效代號與休市都有清楚狀態，不出現假報價。
5. 十張照片均可選取、顯示出處；自訂背景重啟後保留，錯誤圖片有提示。
6. 執行型別檢查、單元測試、正式建置，以及 Chrome 擴充功能的操作驗證；在有個人金鑰後另做兩市場的真實行情與系統通知驗證。
7. 交付可載入的擴充功能目錄及繁體中文安裝說明，區分自動化測試結果與實際行情驗證結果。
