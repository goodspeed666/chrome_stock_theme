# 瀏覽器畫面紀錄

- `default-empty-desktop.png`：空白新分頁預設畫面，未含行情資料。
- `settings-drawer-top.png`：設定抽屜畫面。截圖時 API 金鑰欄位為空白。
- `test-only-fixture-portfolio.png`：自動化測試使用的範例持股畫面；左下角有「測試資料（非即時行情）」標記，畫面價格不是即時報價。
- `compact-stock-cards.png`：緊湊卡片、多市場與長名稱的測試資料畫面，非即時行情。
- `add-stock-no-name.png`：移除手動名稱欄位後的新增表單。
- `add-stock-name-lookup.png`：隔離擴充功能的自動查名測試，使用假 API 回應並有標記，並非真實行情連線證明。

這些 PNG 是瀏覽器自動化擷取的介面檢查素材，不代表已連接個人行情金鑰或驗證即時行情。

- footer-version.png：頁尾版本與台北建置時間，測試預覽畫面。

- greeting-market-open.png：測試時鐘下，開盤時自動隱藏問候區。
- greeting-visibility.png：手動隱藏後，設定中的恢復自動顯示入口。

- limit-notification-settings.png：漲跌停通知與行情更新間隔設定（隔離測試畫面）。
