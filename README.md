# 山嵐股票桌面

以 Chrome Manifest V3 新分頁呈現台股與美股觀察清單。持股、設定和提醒狀態保存在本機；Fugle 與 Finnhub 行情由擴充功能背景程序依排程查詢。沒有 API 金鑰時不會顯示模擬行情。

## 開發與檢查

需要 Node.js `^20.19.0` 或 `>=22.12.0`、npm，以及 Chrome 120 或更新版本。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npx playwright install chromium   # 首次執行端對端測試時
npm run test:e2e
```

`npm run dev` 會啟動本機預覽。預覽使用瀏覽器本機儲存，不呼叫行情 API；請勿將預覽資料當作即時行情驗證。`npm run test:e2e` 會執行操作測試並更新 `artifacts/` 的畫面截圖。

## 安裝 Chrome 擴充功能

1. 在專案根目錄執行 `npm ci` 和 `npm run build`。
2. 在 Chrome 開啟 `chrome://extensions`，開啟「開發人員模式」。
3. 選擇「載入未封裝項目」，指定建置產物目錄 `dist/`。
4. 開啟新分頁，進入「設定」填入自己申請的 Fugle 台股與 Finnhub 美股 API 金鑰。

金鑰欄位以密碼方式遮蔽，資料存放在這個 Chrome 使用者設定檔的 `chrome.storage.local`。請勿把金鑰寫入原始碼、提交至版本控制或分享含有金鑰的截圖。安裝後行情是否可用，取決於 API 金鑰、供應商方案與市場交易狀態；本專案尚未以個人金鑰完成真實行情驗證。

金鑰申請入口：[Fugle 開發者平台](https://developer.fugle.tw/)（台股）、[Finnhub 控制台](https://finnhub.io/dashboard)（美股）。請在各平台取得個人金鑰後，分別填入設定欄位並儲存；方案與可用行情以供應商帳號顯示為準。

## 行情、提醒與損益

行情檢查間隔預設為 30 秒，可在設定選擇 30 秒、1 分鐘、2 分鐘或 5 分鐘；Chrome alarm 會在啟動及設定更新時套用所選間隔。每家供應商共用每分鐘最多 50 次的本機請求預算，每輪最多選取 24 個不同標的。手動更新也共用預算；股票較多時會輪替，遇到限流則退避。卡片顯示供應商的成交時間，因此每次檢查不代表一定有新成交，也不保證每檔股票按固定間隔更新。

提醒只使用有效、未來時間以外且不超過 120 秒的新成交，嚴格比較「高於」或「低於」門檻，相等不觸發。持續符合條件不會重複提醒，回到非觸發區間後才重新啟用。收盤、過期或讀取失敗時保留最後報價作為參考。

台股漲跌停通知預設開啟，只接受 Fugle 成交報價的 `isLimitUpPrice` 或 `isLimitDownPrice` 嚴格布林旗標；試撮、暫停交易、瞬間趨漲跌、同時回報漲停與跌停，或較舊／過期報價都不觸發。通知按台股代號、方向及台北日期每日一次，不從委買委賣或漲跌幅推算；美股不適用。傳送仍需開啟到價提醒並允許瀏覽器通知，關閉通知或權限失效會清除待送事件，恢復後只處理新報價。

關閉單一新分頁不會移除背景排程；Chrome 完全關閉、電腦休眠或離線時不能保證監控與通知。恢復後以新的有效成交繼續判斷，不補送過期行情提醒。

若通知傳送中斷，卡片會保留「通知待送出」或失敗提示，可手動重試。重啟背景程序不會自動補送，以免重複打擾；重試時會再次檢查條件與時效，過期的提醒會清除且不送出。

- 損益百分比：`(目前價格 − 購買成本) ÷ 購買成本 × 100%`。
- 損益金額：`(目前價格 − 購買成本) × 股數`；未填股數時顯示每股差額。
- 點擊卡片損益區可切換百分比與金額。台股使用 NT$、美股使用 US$，不進行匯率換算，也未計入稅費。

## 功能

- 建立台股、美股觀察清單卡片，設定持股成本、股數與高低價提醒。
- 新增股票時輸入代號，會自動查詢並顯示公司／ETF 名稱；需要安裝擴充功能並設定對應市場金鑰。查不到或未設定金鑰時，仍可先用代號加入清單。編輯既有股票可保留手動名稱。
- 股票卡片採緊湊排列，名稱放大至 20px；價格、損益與提醒集中呈現，長名稱及金額可換行。
- 分區可新增、重新命名、排序及刪除；卡片可拖曳、使用選單移動或排序。
- 可切換損益百分比／金額，並選擇十張 CC0 風景背景或上傳本機背景。
- 可選擇行情檢查間隔，並設定是否啟用台股漲跌停通知；通知僅依 Fugle 新成交的限價旗標判斷。
- 追蹤中的任一市場開盤時會自動隱藏問候區，收盤後恢復；也可手動隱藏，並於設定恢復自動顯示。
- 行情請求、提醒狀態與通知由 MV3 service worker 處理；自訂背景圖存於 IndexedDB。

問候區使用內建的 2026 交易日曆：[TWSE 市場開休市日期](https://www.twse.com.tw/rwd/zh/holidaySchedule/holidaySchedule?date=20260101&response=json)及 [NYSE 交易時段與假日](https://www.nyse.com/trade/hours-calendars)。未涵蓋年份會保守顯示問候區；交易所臨時休市或臨時調整時段尚未納入，須更新日曆資料。

提醒受 Chrome 背景執行、網路、電腦休眠和資料供應商限制；請閱讀供應商條款，勿將提醒視為保證成交或持續監控服務。

## 專案結構

- `src/components/`：股票卡片、表單、對話框與設定抽屜。
- `src/domain/`：持股損益、提醒條件、行情新舊判斷與資料型別。
- `src/providers/`：Fugle、Finnhub 行情轉換與錯誤分類。
- `src/background/`：行情排程、背景更新與通知。
- `src/data/`：Chrome／預覽儲存、背景目錄與自訂圖片。
- `public/backgrounds/`：背景原圖、縮圖及照片目錄。
- `tests/unit/`、`tests/e2e/`：單元與瀏覽器操作測試。
- `dist/`：`npm run build` 產生、可載入 Chrome 的擴充功能目錄。
- `artifacts/`：自動化瀏覽器截圖；含測試資料的畫面均有標記。
